# 第一个开发者先行版

Welcome to Rootless Store v0.0.5!

This release marks the first developer preview of Rootless Store. The goal of this version is to establish the app's core architecture, plugin management flow, and Source / Market foundations, while also making the project easier to build on through documentation and open-source setup.

欢迎来到 Rootless Store v0.0.5！

这是 Rootless Store 的第一个开发者先行版。这个版本的重点，是先把应用的核心架构、插件管理流程，以及 Source / Market 的基础能力搭建起来，同时补齐文档与开源基础设施，为后续迭代打下可维护的基础。

---

### What's New in v0.0.5

* **First Developer Preview Release**:
    * Rootless Store now enters its first early preview stage, with the main app structure and initial workflows in place.
* **Core Screens & Navigation**:
    * Added the main app screens, including Home, Plugin, Source, Market, Execute, and Shell, forming the first complete product flow.
* **Plugin Management & Execution Foundations**:
    * Added support for local plugin installation and basic plugin management.
    * Established the initial plugin execution flow and result handling, with clearer status and error feedback.
* **Source & Market Integration**:
    * Added support for Source management and remote plugin source access.
    * Introduced the initial Market integration for discovering and installing plugins from remote endpoints.
* **Multiple Runtime Environment Support**:
    * Added early support for multiple execution environments such as Shizuku, Shell, and Root-related capabilities, lowering the barrier to advanced Android workflows.
* **Open-source & Project Setup**:
    * Added project overview documentation, preview screenshots, AGPLv3 licensing, and initial GitHub Actions / release workflow preparation.

### Key Features

* **Plugin-first Workflow**: Rootless Store focuses on making plugins discoverable, manageable, and executable through a GUI-first experience.
* **Source-based Ecosystem Design**: Plugins can be organized through Sources and remote market-style endpoints, making the ecosystem more decentralized and maintainable.
* **Multiple Runtime Paths**: The project is designed around different execution backends, including Shizuku, Shell, and Root-related capabilities.
* **Host Status Dashboard**: Includes device and environment checks such as Android/API version, kernel, SELinux, plugins, memory, storage, and temperature.
* **Modern Android Stack**: Built with Jetpack Compose, ViewModel, Room, Hilt, Paging, and Ktor for a clearer and more maintainable architecture.

### 主要功能

* **以插件为核心的工作流**: Rootless Store 专注于用 GUI 优先的方式，让插件变得可发现、可管理、可执行。
* **基于 Source 的生态设计**: 通过 Source 和远程 Market 风格端点组织插件来源，使整个生态更加去中心化，也更易维护。
* **多运行路径支持**: 项目围绕多种执行后端设计，包括 Shizuku、Shell 以及 Root 相关能力。
* **宿主状态看板**: 提供 Android/API 版本、Kernel、SELinux、插件数量、内存、存储、温度等状态检查能力。
* **现代化 Android 技术栈**: 基于 Jetpack Compose、ViewModel、Room、Hilt、Paging 与 Ktor 构建，方便后续演进与维护。

### Known Issues & Future Plans

* As the first developer preview, UI details, API contracts, and interaction flows may still change in upcoming releases.
* Market UI, plugin detail presentation, and filtering / state feedback are still being refined.
* Future versions plan to improve permission boundaries, enhance plugin and Source management, and support private, invisible, or paid sources.
